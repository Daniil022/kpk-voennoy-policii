# 📖 Подробная инструкция

## 🔐 Вход в систему

1. Открой КПК
2. Введи пароль: `1234`
3. Сразу смени пароль: **Настройки** → **Смена пароля**

## 🔍 Проверка военнослужащего

1. Вкладка **ПРОВЕРКА**
2. Заполни ФИО (обязательно), остальное — по возможности
3. Статус: ЧИСТ / НАРУШЕНИЯ / В РОЗЫСКЕ / ЗАДЕРЖАН
4. **СОХРАНИТЬ ПРОВЕРКУ**

## 👤 Личные дела

1. Вкладка **ЛИЧНЫЕ ДЕЛА**
2. Заполни поля
3. **СОЗДАТЬ ДЕЛО**
4. Для добавления события — кнопка **+ЗАПИСЬ** в карточке
5. Тип события: `green` (нейтральное), `yellow` (предупреждение), `red` (нарушение)

## 📋 Протоколы

1. Вкладка **ПРОТОКОЛ**
2. Заполни все поля
3. **ЗАФИКСИРОВАТЬ**
4. Кнопка 🖨 — печать протокола
5. **В АРХИВ** — перенести закрытое дело

## 🎯 Ориентировки

1. Вкладка **ОРИЕНТИРОВКИ**
2. Приоритет: 🔴 высокий / 🟠 средний / 🟢 низкий
3. **ОПУБЛИКОВАТЬ**

## 📖 Журнал

- Заполняется **автоматически** при любых действиях
- Можно добавить **ручную запись** (тип: ПАТРУЛЬ / ЗАДЕРЖАНИЕ / ОПЕРАЦИЯ / СОБЫТИЕ)
- Есть поиск по журналу

## 📁 Архив

- **Автоматически**: кнопка «В АРХИВ» в розыске/протоколах
- **Вручную**: заполни поля и нажми «В АРХИВ»

## 💾 Резервная копия

1. **Настройки** → **ЭКСПОРТ В ФАЙЛ**
2. Сохрани JSON-файл в надёжное место
3. Восстановление: **ИМПОРТ ИЗ ФАЙЛА**

⚠ **Делай экспорт раз в неделю!** Если очистишь кэш браузера — данные пропадут.

## 🖨 Печать

- В протоколах нажми иконку 🖨
- Откроется отдельное окно с чистой вёрсткой A4
- Ctrl+P → Сохранить как PDF

## ⌨ Горячие клавиши

- **Enter** на экране входа — войти
- **Ctrl+P** — печать (в окне печати протокола)
