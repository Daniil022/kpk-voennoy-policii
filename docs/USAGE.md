# 📖 Подробная инструкция

## 🔐 Вход в систему

1. Открой КПК
2. Логин: `admin`, пароль: `1234`
3. Сразу смени пароль: **Настройки** → **Смена пароля**

## 👥 Управление сотрудниками

Только для **лидера** и **зама** (вкладка СОТРУДНИКИ):

- **＋ ДОБАВИТЬ СОТРУДНИКА** — логин, пароль, имя, роль
- **РОЛЬ** — сменить роль (leader / deputy / officer / cadet)
- **ПАРОЛЬ** — сбросить пароль
- **БАН** — заблокировать доступ
- **✕** — удалить сотрудника

## 🔊 Звуки

Вкладка **ЗВУКИ**:
- Регулятор глобальной громкости
- Кнопки **▶ ИГРАТЬ** для тестирования каждого из 25 звуков

Кнопка **🔊 / 🔇** в шапке — быстрое выключение звука.

**Горячие звуковые события:**
- Клик по кнопкам — `button`
- Сохранение — `save`
- Ошибка — `error`
- В розыск — `alarm` + `walkie`
- Вход — `login` + `hack` + голос «Доступ разрешён»
- Переключение вкладок — `radio` + `kpkDoor`

## 📋 Разделы

- **ПРОВЕРКА** — экспресс-проверка военнослужащего
- **ЛИЧНЫЕ ДЕЛА** — карточки с историей (кнопка +ЗАПИСЬ)
- **ПРОТОКОЛ** — оформление протокола с печатью
- **РОЗЫСК** — база разыскиваемых с наградой
- **ОРИЕНТИРОВКИ** — приоритеты 🔴🟠🟢
- **ЖУРНАЛ** — авто + ручные записи
- **АРХИВ** — завершённые дела
- **ЗАМЕТКИ** — личные записи
- **СОТРУДНИКИ** — управление офицерами
- **НАСТРОЙКИ** — пароль, Firebase, экспорт/импорт

## 💾 Резервная копия

**Настройки** → **ЭКСПОРТ** — сохрани JSON
**Настройки** → **ИМПОРТ** — восстанови данные

⚠ Делай экспорт раз в неделю!
