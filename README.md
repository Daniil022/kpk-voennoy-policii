# 🔐 КПК Военной Полиции v4.0 | Live Russia

Полнофункциональный КПК для Военной Полиции с **звуками, Firebase-синхронизацией и ролями офицеров**.

## 🌐 Онлайн-версия

👉 **[Открыть КПК](https://ТВОЙ_НИК.github.io/kpk-mvd/)**

Замени `ТВОЙ_НИК` на свой ник на GitHub.

## ✨ Возможности

### 🔊 Звуки (25 штук, Web Audio API — без файлов)
Писк кнопки, сохранение, ошибка, тревога, вход/выход, неверный пароль, уведомление, печать, радиопомехи, взлом, сканирование, цифровой отказ, тиканье, SOS (азбука Морзе), скрип двери, рация, фанфары, спецсигнал (сирена), взрыв/штурм, печатная машинка, скрип КПК.

### ☁️ Firebase-синхронизация
Общая база для всей фракции в реальном времени. Индикатор СИНХРО/ОФЛАЙН.

### 👥 Роли и логины
| Роль | Доступ |
|------|--------|
| **ЛИДЕР** | Полный |
| **ЗАМ** | Всё кроме управления лидером |
| **ОФИЦЕР** | Основные разделы |
| **СТАЖЁР** | Только проверки + ориентировки |

### 📂 Разделы
Проверка · Личные дела · Протоколы · Розыск · Ориентировки · Журнал · Архив · Заметки · Сотрудники · Звуки · Настройки

## 🚀 Быстрый старт

1. Открой ссылку выше
2. Логин `admin`, пароль `1234`
3. Смени пароль в **Настройках**
4. Добавь сотрудников в разделе **СОТРУДНИКИ**
5. Подключи Firebase (инструкция в `docs/FIREBASE_SETUP.md`)

## 📱 Установка на телефон

1. Открой ссылку в браузере телефона
2. Меню → **Добавить на главный экран**
3. Работает как приложение

## 🔒 Безопасность

- Локально: `localStorage`
- Firebase: правила Firestore (настрой для продакшена!)
- Сделай экспорт данных раз в неделю
