# 🔐 КПК Военной Полиции | Live Russia

Удалённый КПК для сотрудников Военной Полиции в игре Live Russia.

## 🌐 Онлайн-версия
👉 **[Открыть КПК](https://ТВОЙ_НИК.github.io/kpk-mvd/)**

## ✨ Возможности
- 🔐 Пароль на вход
- 🔍 Экспресс-проверка военнослужащих
- 👤 Личные дела с историей (таймлайн)
- 📋 Протоколы задержания
- 🎯 Ориентировки с приоритетами
- ⚠ База розыска
- 📖 Журнал событий (авто + ручной)
- 📁 Архив закрытых дел
- 📝 Личные заметки
- 💾 Экспорт/импорт данных (JSON)

## 🚀 Использование
1. Открой ссылку выше
2. Введи пароль: `1234`
3. Смени пароль в «Настройках»
4. Делай экспорт раз в неделю

## 🔒 Безопасность
Все данные хранятся локально в браузере (localStorage).
Сервер не используется. Никто кроме тебя не имеет доступа.
